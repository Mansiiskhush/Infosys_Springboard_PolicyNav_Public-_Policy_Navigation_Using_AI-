Infosys Springboard Internship - Milestone 2

Project Overview

This project is an evolution of Milestone 1, focusing on enhanced security and data visualization. The primary goal of this update was to integrate OTP Authentication and a Readability Dashboard while improving the overall UI/UX.

Features Updated

•	OTP Authentication: Added a secure layer for user verification.

•	Readability Dashboard: Implemented visual analytics to track key project metrics.

•	UI/UX Improvements: Refined the interface for a smoother, more professional user experience.

•	Performance Optimization: Conducted thorough testing to ensure all features are functional.
Folder Contents

This Milestone2 folder contains:

•	Project_Notebook.ipynb: The main Google Colab file with updated code.

•	Source Code: Relevant Python files and logic.

•	Screenshots: Visual evidence of the working application.
